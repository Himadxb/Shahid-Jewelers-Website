# Shahid Jewelers Website

A premium e-commerce website for Shahid Jewelers, featuring a live gold rate tracker and an elegant dark-themed design.

## Features

- **Live Gold Rate Tracker**: Real-time updates for Gold prices in USD and AED (Simulated for demo purposes).
- **Premium Design**: Luxurious dark theme with gold accents, using 'Playfair Display' and 'Inter' fonts.
- **Responsive Layout**: Fully responsive for mobile and desktop.
- **Shop Page**: Product catalog with category filtering.
- **Product Details**: Hover effects and "Add to Cart" interactions.

## Tech Stack

- **React (Vite)**: Fast and modern frontend framework.
- **Vanilla CSS**: Custom styling with CSS variables for maximum control.
- **Framer Motion**: Smooth animations for a premium feel.
- **Lucide React**: Beautiful icons.
- **React Router**: Seamless navigation.

## Getting Started

1.  **Install Dependencies**:

    ```bash
    npm install
    ```

2.  **Run Development Server**:

    ```bash
    npm run dev
    ```

3.  **Open in Browser**:
    Visit `http://localhost:5173`

## Project Structure

- `src/components`: Reusable UI components (Navbar, GoldTicker, ProductCard, etc.)
- `src/pages`: Route pages (Home, Shop)
- `src/context`: Global state management (GoldContext)
- `src/styles`: Global styles
